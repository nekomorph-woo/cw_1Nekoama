## 📖 简介

**Nekoama** 是一款功能强大的 IntelliJ IDEA 插件，通过集成先进的大语言模型技术，为开发者提供全方位的智能代码辅助功能。插件深度分析代码上下文，理解开发意图，并提供精准的智能建议，显著提升编码效率和代码质量。

### 🎯 设计理念

- **智能理解**: 基于 PSI 和 AST 分析，深度理解代码结构和语义
- **上下文感知**: 提取丰富的代码上下文，生成符合项目规范的建议
- **安全可靠**: 所有敏感数据加密存储，网络请求异步处理
- **模块化架构**: 可扩展的插件式架构，支持自定义功能扩展
- **性能优先**: 后台处理，不阻塞 UI，保持 IDE 流畅响应

## ✨ 核心功能

### 📝 智能命名建议
- **变量命名**: 基于变量类型、用途和作用域智能生成符合驼峰命名规范的变量名
- **方法命名**: 根据方法功能、参数和返回值生成语义清晰的方法名
- **类命名**: 结合类职责和继承关系生成符合 Java/Kotlin 命名约定的类名
- **命名规范**: 自动遵循项目现有的命名模式和最佳实践

### 📖 AI 驱动注释生成
- **方法注释**: 自动生成符合 KDoc/JavaDoc 规范的完整方法文档
- **参数说明**: 智能分析参数类型和用途，生成清晰的参数描述
- **返回值描述**: 基于方法逻辑生成准确的返回值说明
- **异常文档**: 自动识别可能抛出的异常并生成相关文档
- **代码示例**: 根据方法复杂度生成使用示例代码

### 🛠️ 自定义代码生成
- **灵活提示**: 支持自然语言描述，生成任何类型的代码内容
- **上下文集成**: 自动结合当前代码环境，生成符合项目风格的代码
- **模板生成**: 支持算法实现、设计模式、重构建议等多种模板
- **增量生成**: 可在选中位置插入生成内容，支持多次迭代优化

### 🔍 未使用代码分析
- **全项目扫描**: 深度分析整个项目，识别未使用的文件、类、方法和属性
- **智能过滤**: 排除测试文件、配置文件等特殊用途的代码
- **详细报告**: 生成包含位置、类型和影响范围的详细分析报告
- **一键清理**: 提供安全的代码清理建议，支持批量操作

## 🚀 安装方法

### 方式一：从 JetBrains Marketplace 安装（推荐）
1. 打开 IntelliJ IDEA
2. 进入 **File** → **Settings** → **Plugins**
3. 搜索 "Nekoama"
4. 点击 **Install** 安装
5. 重启 IDE

### 方式二：手动安装
1. 从 [Releases](https://github.com/your-repo/releases) 下载最新版本的插件包
2. 打开 IntelliJ IDEA
3. 进入 **File** → **Settings** → **Plugins**
4. 点击 ⚙️ 图标，选择 **Install Plugin from Disk...**
5. 选择下载的插件包文件
6. 重启 IDE

### 方式三：从源码构建
```bash
# 克隆项目
git clone https://github.com/your-repo/nekoama.git
cd nekoama

# 构建插件
./gradlew buildPlugin

# 运行沙盒 IDE
./gradlew runIde
```

## 🔧 快速开始

### 1. 配置 AI 服务
1. 打开 **File** → **Settings** → **Tools** → **Nekoama**
2. 选择 AI 提供商（OpenAI API兼容的提供商）
3. 输入 API 密钥和相关配置
4. 点击 **Test Connection** 验证配置

### 2. 使用智能命名
- 选中需要命名的变量、方法或类
- 右键选择 **Nekoama** → **Name for Any**
- 或者使用快捷键 `Ctrl+Alt+N`（可在设置中自定义）

### 3. 生成代码注释
- 将光标置于需要注释的方法或类上
- 右键选择 **Nekoama** → **Comment for Me**
- 或者使用快捷键 `Ctrl+Alt+C`

### 4. 自定义代码生成
- 选中包含需求描述的文本
- 右键选择 **Nekoama** → **IDEA for Neko**
- 支持格式：`[你的需求描述]` 或直接使用选中文本

### 5. 分析未使用代码
- 打开 **Tools** 菜单
- 选择 **Nekoama: Analyze Unused Code**
- 等待分析完成，查看生成的报告文件

## 🏗️ 技术架构

### 分层架构设计
```
┌─────────────────────────────────────┐
│           Presentation Layer        │  # UI 层：动作、工具窗口、设置
├─────────────────────────────────────┤
│           Integration Layer         │  # 集成层：PSI、编辑器、生命周期
├─────────────────────────────────────┤
│              Core Layer             │  # 核心层：异常、日志、指标、序列化
├─────────────────────────────────────┤
│               AI Layer              │  # AI 层：模型、提供商、客户端
└─────────────────────────────────────┘
```

### 关键技术特性
- **PSI 安全**: 所有 PSI 访问都通过 `ReadAction` 保护，确保线程安全
- **EDT 兼容**: UI 操作正确使用事件分发线程，后台任务不阻塞界面
- **异步处理**: 基于 Kotlin 协程的异步架构，支持任务取消和进度跟踪
- **模块化设计**: 插件式扩展系统，支持动态加载和卸载
- **状态持久化**: 自动保存和恢复界面状态及用户配置
- **OkHttp 优化**: 采用 OkHttp 作为网络客户端，提供更强大的性能和功能

### 核心组件
- **UniversalCodeAnalyzer**: 统一的代码分析器，支持 Java 和 Kotlin
- **AIProvider**: 抽象的 AI 服务接口，支持多种提供商
- **ModularToolWindow**: 模块化工具窗口，支持动态标签页
- **TokenStatsTab**: Token 使用统计和可视化
- **MetricsCollector**: 使用指标收集和分析
- **CustomAPIHttpClient**: 基于 OkHttp 的高性能 HTTP 客户端，支持智能重试、性能监控和代理配置

## 🌐 网络配置和代理支持

### 代理配置
Nekoama 支持企业网络环境下的代理配置。插件会自动检测并使用 IDEA 的系统代理设置。

#### HTTP/HTTPS 代理
1. 打开IDEA：`文件` → `设置` → `系统设置` → `HTTP代理`
2. 选择 `手动代理配置`
3. 配置代理设置：
   - **HTTP代理**：HTTP流量的主机名和端口
   - **HTTPS代理**：HTTPS流量的主机名和端口
   - **代理认证**：如果需要，输入用户名和密码
4. 点击 `确定` 应用设置

#### SOCKS代理
1. 在同一代理设置对话框中，为代理类型选择SOCKS
2. 输入SOCKS代理服务器详细信息
3. 确保代理服务器支持SOCKS4/5协议
4. 如果需要，配置身份验证

### 代理认证故障排除

#### HTTP 407：代理认证要求
**症状**：连接AI服务时出现"代理认证失败"错误消息
**解决方案**：
- 在IDEA代理设置中验证代理用户名和密码
- 检查代理服务器是否需要域认证（使用 `域名\用户名` 格式）
- 首先用网页浏览器测试代理连接
- 联系网络管理员获取正确的代理凭据

#### 代理环境中的连接超时
**症状**：使用代理时请求超时
**解决方案**：
- 在Nekoama设置中增加超时值（`文件` → `设置` → `工具` → **Nekoama**）
- 检查代理服务器性能和网络稳定性
- 验证防火墙设置允许代理连接
- 如果可用，尝试不同的代理服务器

### 网络诊断工具

#### 测试连接
使用Nekoama设置中的内置连接测试：
1. 打开 `文件` → `设置` → `工具` → **Nekoama**
2. 配置您的API端点和API密钥
3. 点击 **测试连接** 验证网络连接
4. 检查结果中的代理认证状态和响应时间

#### 错误识别
**插件错误**（Nekoama相关）：
- 包名以 `com.cw2.nekoama` 开头
- 出现在Nekoama工具窗口或设置中
- 与AI服务调用或配置相关

**IDE错误**（IntelliJ IDEA相关）：
- 包名以 `com.intellij` 开头
- 在IDE启动期间出现
- 与IDEA内置功能（AI Assistant等）相关

## ❓ 常见问题解答

### Q：出现"代理认证要求"错误怎么办？
**A**：这表示您的代理服务器需要身份验证。检查IDEA代理设置（`文件` → `设置` → `系统设置` → `HTTP代理`），确保配置了正确的用户名和密码。

### Q：插件显示"连接失败"但互联网正常工作？
**A**：这可能是代理配置问题。先用浏览器测试，然后验证IDEA代理设置是否与系统代理配置匹配。

### Q：如何验证代理是否正常工作？
**A**：使用Nekoama设置中的内置连接测试。测试会显示代理状态、响应时间和任何身份验证问题。

### Q：可以为不同请求使用不同的代理吗？
**A**：Nekoama遵循IDEA的全局代理设置。对于不同的代理配置，您需要手动修改IDEA的代理设置。

### Q：在代理环境中出现SSL证书错误怎么办？
**A**：配置您的代理以允许SSL连接，或者在Nekoama设置中临时禁用SSL验证（不推荐在生产环境中使用）。

### Q：如何区分Nekoama错误和其他插件错误？
**A**：检查错误日志的包名。Nekoama错误以`com.cw2.nekoama`开头，而其他插件有不同的包前缀。

### Q：插件在没有代理的情况下工作正常，但启用代理后失败？
**A**：这通常表示代理身份验证问题。验证凭据并确保代理允许到您的AI服务端点的HTTPS连接。
